# Esqueleto do artigo (IMRaD)

Metas de palavras = sugestão do livro-base. **Os limites da revista ou do evento sempre prevalecem.**

| Seção | Meta (livro-base) | Conteúdo |
|---|---|---|
| Título | 10–20 palavras | Claro, específico, sem ponto final, com nome científico quando houver |
| Autores e afiliações | — | Ordem por contribuição; instituição, unidade, e-mail; ORCID |
| Resumo | 200–300 (ou limite da revista) | Contexto → objetivo → métodos (com local) → resultados → conclusão |
| Palavras-chave | 3–6 | Diferentes das do título |
| Abstract / Resumen | igual ao resumo | Versão fiel, revisada por humano |
| 1 Introdução | 400–800 | Cone invertido: presente → passado → futuro → objetivo |
| 2 Material e Métodos | 600–900 | Local, material, delineamento, procedimentos, análise, ética |
| 3 Resultados | 400–500 | Ordem dos objetivos; figuras/tabelas sem redundância |
| 4 Discussão | 400–800 | Interpretação e comparação com a literatura |
| 5 Conclusão | curta | Responde ao objetivo; tópicos quando couber |
| Agradecimentos | curto | Fomento (com nº de processo), instituições, apoio técnico |
| Declarações | — | Ética, conflito de interesses, financiamento, dados, uso de IA, CRediT |
| Referências | — | Só as citadas; recentes; estilo da revista |

Variações:
- **Resumo expandido de congresso**: geralmente 2–5 páginas; Introdução + Métodos + Resultados e Discussão + Conclusão, poucas referências.
- **Artigo completo de congresso**: seguir o template do evento (ex.: SBC, IEEE, ACM, Springer LNCS).
- **Nota científica**: texto corrido, sem subdivisões, 2 resumos e referências.
- **Revisão**: introdução, método de busca (ex.: PRISMA para sistemática), corpo temático, considerações finais.
